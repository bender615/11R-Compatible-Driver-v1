# Security policy

This project is experimental driver software and is not yet a production-ready
or vendor-supported driver.

Please report a suspected security vulnerability privately through the
repository's GitHub **Security** tab using a private vulnerability report. Do
not include credentials, signing material, private device captures, or other
sensitive data in a public issue.

There is currently no committed security-support window or guaranteed response
time. Public compatibility bugs and reproducible crashes that do not disclose
sensitive information may be filed through the issue tracker.
